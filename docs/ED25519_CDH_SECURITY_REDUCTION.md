# Security Reduction of Ed25519 Digital Signatures Under the Computational Diffie-Hellman (CDH) Assumption

## Abstract

This paper presents the formal cryptographic security reduction claim submitted for independent third-party cryptographic review of the VADP audit ledger signature scheme. We prove that the Ed25519 digital signature scheme (RFC 8032) achieves Existential Unforgeability under Chosen-Message Attack (EUF-CMA) in the random oracle model, reducing signature unforgeability directly to the hardness of the Computational Diffie-Hellman (CDH) problem over the twisted Edwards curve $\text{Ed25519}$.

---

## 1. System Model & Cryptographic Primitives

Let $\mathbb{G}$ be the prime-order subgroup of the twisted Edwards curve $-x^2 + y^2 = 1 + d x^2 y^2$ over $\mathbb{F}_q$ where $q = 2^{255} - 19$, generated by base point $B$ of prime order $\ell = 2^{252} + 27742317777372353535851937790883648493$.

* **Key Generation**: Pick private scalar $s \in_R \mathbb{Z}_\ell$. Compute public key $A = s \cdot B \in \mathbb{G}$.
* **Signing Protocol**: For message $M \in \{0,1\}^*$:
  1. Compute deterministic nonce scalar $r = H(h_b, \ldots, h_{2b-1} \parallel M) \bmod \ell$, where $(h_0, \ldots, h_{2b-1}) = H(s)$.
  2. Compute commitment point $R = r \cdot B \in \mathbb{G}$.
  3. Compute challenge scalar $k = H(R \parallel A \parallel M) \bmod \ell$.
  4. Compute signature scalar $S = (r + k \cdot s) \bmod \ell$.
  5. Emit signature pair $\sigma = (R, S) \in \mathbb{G} \times \mathbb{Z}_\ell$.
* **Verification**: Check $S \cdot B \stackrel{?}{=} R + k \cdot A$.

---

## 2. Computational Assumptions

### Definition 1 (Computational Diffie-Hellman (CDH) Assumption over Ed25519)
Let $\mathcal{A}$ be a probabilistic polynomial-time (PPT) adversary. The CDH advantage of $\mathcal{A}$ in $\mathbb{G}$ is defined as:
$$\text{Adv}_{\mathbb{G}}^{\text{CDH}}(\mathcal{A}) = \Pr\left[ \mathcal{A}(B, X=x B, Y=y B) = z B \quad \middle|\quad x, y \in_R \mathbb{Z}_\ell \text{ and } z \equiv x y \bmod \ell \right]$$
The CDH assumption holds if $\text{Adv}_{\mathbb{G}}^{\text{CDH}}(\mathcal{A}) \le \epsilon_{\text{CDH}}$ for all PPT adversaries $\mathcal{A}$.

---

## 3. Main Theorem & Security Reduction

### Theorem 1 (Ed25519 EUF-CMA Security Reduction)
Suppose there exists a PPT adversary $\mathcal{F}$ that breaks the EUF-CMA security of the Ed25519 signature scheme in time $T$, making at most $q_H$ queries to the random oracle $H$ and at most $q_S$ queries to the signing oracle, with success probability $\epsilon_{\text{forge}}$. Then there exists an algorithm $\mathcal{B}$ that solves the Computational Diffie-Hellman (CDH) problem over $\mathbb{G}$ with probability:

$$\epsilon_{\text{CDH}} \ge \frac{\epsilon_{\text{forge}} - q_S (q_H + q_S) / \ell}{q_H}$$

in time $T' \le T + \mathcal{O}((q_H + q_S) \cdot t_{\text{mult}})$, where $t_{\text{mult}}$ is the cost of scalar multiplication in $\mathbb{G}$.

## 4. Reduction Proof Sketch

1. **Setup**: The simulator $\mathcal{B}$ receives a CDH challenge tuple $(B, X = x B, Y = y B)$. $\mathcal{B}$ sets the public key $A = X = x B$.
2. **Oracle Simulation**:
   - **Random Oracle $H$**: $\mathcal{B}$ maintains a lookup table for $H$ queries. When queried on $(R \parallel A \parallel M)$, $\mathcal{B}$ returns a uniformly random scalar $k \in \mathbb{Z}_\ell$.
   - **Signing Oracle**: For message $M_i$, $\mathcal{B}$ picks $S_i, k_i \in_R \mathbb{Z}_\ell$, sets $R_i = S_i B - k_i A$, and programs $H(R_i \parallel A \parallel M_i) = k_i$. The signature $(R_i, S_i)$ is perfectly indistinguishable from a genuine signature.
3. **Forgery & Forking Lemma**: By applying the General Forking Lemma (Pointcheval & Stern), if $\mathcal{F}$ outputs a valid forgery $(R^*, S^*)$ on message $M^*$, $\mathcal{B}$ rewinds $\mathcal{F}$ to the random oracle query $(R^* \parallel A \parallel M^*)$ and supplies a fresh independent response $k' \neq k^*$.
4. **Extraction**: $\mathcal{F}$ produces two valid signatures $(R^*, S^*)$ and $(R^*, S')$ satisfying:
   $$S^* B = R^* + k^* A \quad \text{and} \quad S' B = R^* + k' A$$
   Subtracting the two equations yields:
   $$(S^* - S') B = (k^* - k') A = (k^* - k') x B$$
   Since $k^* \not\equiv k' \pmod \ell$, $\mathcal{B}$ extracts the private scalar $x = (S^* - S')(k^* - k')^{-1} \bmod \ell$.
5. **CDH Solution**: With $x$ extracted, $\mathcal{B}$ computes $x Y = x (y B) = (x y) B$, which is the exact solution to the CDH challenge. $\blacksquare$
